## Section 01. 순차 자료구조와 선형 리스트의 이해

### 1 순차 자료구조의 개념

- 자료는 구조화 방법에 따라 **리스트, 스택, 큐, 데크, 트리, 그래프** 등으로 나뉨
- 프로그램으로 구현하는 방식: **순차 자료구조** vs **연결 자료구조(4장)**
- **순차 자료구조**: 구현할 자료들을 논리적인 순서대로 메모리에 연속 저장
    - 논리적인 순서와 물리적인 순서가 **항상 일치**해야 함
    - C 프로그래밍에서 제공하는 구현 기법: **배열(Array)**

### 표 3-1 순차 자료구조 vs 연결 자료구조 비교

| 구분 | 순차 자료구조 | 연결 자료구조 |
| --- | --- | --- |
| 메모리 저장 방식 | 시작 위치부터 빈자리 없이 순서대로 연속 저장. **논리적 순서 = 물리적 순서** | 저장된 물리적 위치나 물리적 순서와 상관없이 링크에 의해 논리적인 순서 표현. 물리적 순서 ≠ 논리적 순서 |
| 연산 특성 | 삽입·삭제 시 빈자리 없이 자료가 순서대로 연속하여 저장되도록 변경. **논리적 순서와 저장된 물리적 순서가 항상 일치** | 삽입·삭제 연산 시 논리적 순서가 변경되어도 링크 정보만 변경되고 물리적 순서는 변경되지 않음 |
| 프로그램 기법 | **배열**을 이용한 구현 | **포인터**를 이용한 구현 |

---

### 2 선형 리스트의 표현

- **리스트**: 자료를 구조화하는 가장 기본적인 방법 = 나열
- 원소를 순서대로 나열한 리스트 → **선형 리스트(Linear List)** 또는 **순서 리스트(Ordered List)**

### 리스트 표현 형식

```
리스트 이름 = (원소 1, 원소 2, …, 원소 n)
동창 = (상원, 상범, 수영, 현정)
```

- **공백 리스트**: 원소가 하나도 없는 리스트 → `공백 리스트 이름 = ( )`

### 선형 리스트의 구현 방식

| 구분 | 설명 |
| --- | --- |
| **선형 순차 리스트** (Linear Sequential List) | 원소를 논리적 순서대로 메모리에 **연속하여 저장** (순차 자료구조 방식) |
| **선형 연결 리스트** (Linear Linked List) | 원소를 논리적 순서대로 **연결**하여 구성 (연결 자료구조 방식) |

> ☞ 일반적으로 선형 순차 리스트 → **선형 리스트**, 선형 연결 리스트 → **연결 리스트(Linked List)**
> 
- 선형 리스트(선형 순차 리스트)는 원소들의 **논리적 순서와 물리적 순서가 일치**하는 순차 자료구조 방식

### 3 선형 리스트의 배열 표현

### 1차원 배열을 이용한 선형 리스트 표현

- 배열은 `<인덱스, 원소>` 쌍으로 구성, 메모리에 연속적으로 할당
- C 프로그래밍 언어의 배열 인덱스는 **0부터 시작**
- 각 원소의 위치:

```
원소 위치 = α + (배열의 인덱스 × ℓ)
         = α + (i−1) × ℓ   (i번째 원소)
```

> α = 시작 주소, ℓ = 원소 크기(바이트)
> 

### 표 3-4 분기별 노트북 판매량 리스트 (1차원 배열 예)

| 1/4분기 | 2/4분기 | 3/4분기 | 4/4분기 |
| --- | --- | --- | --- |
| 157 | 209 | 251 | 312 |

```c
int sale[4] = { 157, 209, 251, 312 };
// 각 원소의 위치 = α + (인덱스 × 4바이트)
```

### 📌 예제 3-1 원소의 논리적·물리적 순서 확인하기 (p.124)

```c
#include <stdio.h>
int main(void) {
    int i, sale[4] = {157, 209, 251, 312};
    for (i = 0; i < 4; i++) {
        printf("\n address : %u sale[%d]= %d", &sale[i], i, sale[i]);
    }
    getchar(); return 0;
}
```

**실행 결과:**

```
address : 5241668  sale[0]= 157
address : 5241672  sale[1]= 209
address : 5241676  sale[2]= 251   ← (강조)
address : 5241680  sale[3]= 312
```

**결과 분석:**

```
sale[2]=251의 위치 = 시작 주소 + (인덱스 × 4바이트)
                  = 5241668 + (2 × 4바이트)
                  = 5241676
→ 논리적 순서대로 메모리에 연속 저장된 순차 구조 확인!
```

### 2차원 배열을 이용한 선형 리스트 표현

- 2가지 순서를 동시에 표현할 때 사용
- 2차원 논리 구조를 1차원 물리 구조로 변환하는 방법 필요

### 표 3-5 2021~2022년 분기별 노트북 판매량 리스트

| 연도 | 1/4분기 | 2/4분기 | 3/4분기 | 4/4분기 |
| --- | --- | --- | --- | --- |
| 2021년 | 63 | 84 | 140 | 130 |
| 2022년 | 157 | 209 | 251 | 312 |

```c
int sale[2][4] = { { 63, 84, 140, 130 },
                   { 157, 209, 251, 312 } };
```

### 2차원 배열의 물리적 저장 방법

| 방법 | 기준 | 원소 위치 공식 |
| --- | --- | --- |
| **행 우선 순서 (Row Major Order)** | 첫 번째 인덱스 (행 번호) 기준 | `α + (i × nj + j) × ℓ` |
| **열 우선 순서 (Column Major Order)** | 마지막 인덱스 (열 번호) 기준 | `α + (j × ni + i) × ℓ` |

> ni = 행의 개수, nj = 열의 개수, α = 시작 주소, ℓ = 원소 길이
> 

**행 우선 순서 저장 예:**

```
sale[0][0]=63, sale[0][1]=84, sale[0][2]=140, sale[0][3]=130,
sale[1][0]=157, sale[1][1]=209, sale[1][2]=251, sale[1][3]=312
```

**열 우선 순서 저장 예:**

```
sale[0][0]=63, sale[1][0]=157, sale[0][1]=84, sale[1][1]=209,
sale[0][2]=140, sale[1][2]=251, sale[0][3]=130, sale[1][3]=312
```

> ☞ **C 컴파일러는 행 우선 순서 방법 사용**
> 

### 📌 예제 3-2 2차원 배열의 논리적·물리적 순서 확인하기 (p.126)

```c
#include <stdio.h>
int main(void) {
    int i, n = 0, *ptr;
    int sale[2][4] = {{63, 84, 140, 130},
                      {157, 209, 251, 312}};  // 2차원 배열의 초기화
    ptr = &sale[0][0];
    for (i = 0; i < 8; i++) {
        printf("\n address : %u sale %d = %d", ptr, i, *ptr);
        ptr++;
    }
    getchar(); return 0;
}
```

**결과 분석 (행 우선 순서 확인):**

```
α + (i × nj + j) × ℓ
= 1374812 + (1 × 4 + 2) × 4
= 1374812 + 24
= 1374836
→ C 컴파일러가 행 우선 순서 방법으로 2차원 배열 저장 확인!
```

### 3차원 배열의 물리적 저장 방법

| 방법 | 기준 | 원소 위치 공식 |
| --- | --- | --- |
| **면 우선 순서** | 첫 번째 인덱스 (면 번호) 기준 | `α + {(i × nj × nk) + (j × nk) + k} × ℓ` |
| **열 우선 순서** | 마지막 인덱스 (열 번호) 기준 | `α + {(k × nj × ni) + (j × ni) + i} × ℓ` |

> ni = 면의 개수, nj = 행의 개수, nk = 열의 개수
> 

### 📌 예제 3-3 3차원 배열의 논리적·물리적 순서 확인하기 (p.129)

```c
#include <stdio.h>
int main(void) {
    int i, n = 0, *ptr;
    int sale[2][2][4] = {{{63, 84, 140, 130},   // 3차원 배열의 초기화
                          {157, 209, 251, 312}},
                         {{59, 80, 130, 135},
                          {149, 187, 239, 310}}};
    ptr = &sale[0][0][0];
    for (i = 0; i < 16; i++) {
        printf("\n address : %u sale %2d = %3d", ptr, i, *ptr);
        ptr++;
    }
    getchar(); return 0;
}
```

**결과 분석 (면 우선 순서 확인):**

```
α + {(i × nj × nk) + (j × nk) + k} × ℓ
= 1374524 + {(1 × 2 × 4) + (1 × 4) + 2} × 4
= 1374524 + 56
= 1374580  (sale[1][1][2] = 239 위치)
→ C 컴파일러가 면 우선 순서 방법으로 3차원 배열 저장 확인!
```

### ⚠️ 순차 자료구조의 장단점

| 장점 | 단점 |
| --- | --- |
| 원소 순서를 따로 표시할 필요 없이 물리적 주소의 순서로 간단히 구성 가능 | 삽입·삭제 시 물리적으로 원소들을 뒤로 밀거나 앞으로 당겨서 연속 저장 순서를 유지해야 함 → **추가적인 오버헤드 발생** |
| 인덱스로 주소 계산 가능 → 특정 원소를 쉽게 액세스 | 읽기·쓰기(업데이트)·순차 액세스 같은 연산에서는 효율적이지만, **삽입·삭제 연산이 많은 문제에서는 비효율적** |

## Section 02. 선형 리스트의 연산과 알고리즘

### 1 선형 리스트에서 원소 삽입과 알고리즘

- 선형 리스트는 순차 자료구조 방식으로 구현하므로, 삽입 후 변경된 논리적 순서와 메모리에 연속 저장된 물리적 순서가 **일치**해야 함
- 새로운 원소를 삽입하려면: **먼저 물리적으로 삽입할 자리를 만든 후에 원소를 삽입**

### 원소 삽입 과정 (예: 인덱스 2번 자리에 원소 30 삽입)

```
삽입 전: [10][20][40][50][60][70]  (인덱스 0~5, n=6)
         ↓ 인덱스 5부터 2까지 한 자리씩 뒤로 이동
삽입 후: [10][20][30][40][50][60][70]  (인덱스 0~6, n=7)
```

- 이동 횟수 = n−k+1 (마지막 원소의 인덱스 − 삽입할 자리의 인덱스 + 1)
- 예: 2번 자리에 삽입, n=5 → 이동 횟수 = 5−2+1 = **4회**

> **TIP**: 원소가 n개인 선형 리스트에서 k번 자리에 원소를 삽입하려면 k번 원소부터 마지막 원소인 n번 원소까지 총 n−k+1개의 원소를 모두 한 자리씩 뒤로 옮겨야 한다.
> 

### 알고리즘 3-1 선형 리스트의 원소 삽입

```
insertElement(L, n, x)
① for (i ← 0; i≤n; i ← i+1) do {
    ①-❶ if (L[i] ≤ x && x ≤ L[i+1]) then {
           ①-❷ k ← i+1;
                break;
         }
   }
② if (i == n) then k ← n;
③ for (i ← n; i > k; i ← i−1) do   // n-1번부터 k번까지
       L[i] ← L[i-1];                 // 뒤로 한 자리 이동
④ L[k] ← x;
end insertElement()
```

- **❶** 선형 리스트 L에서 원소의 크기를 비교하여 삽입 원소 x의 삽입 위치 k를 찾는다.
- **❷** 삽입 위치가 없는 경우, 즉 삽입 원소 x가 가장 큰 원소이면 마지막 원소의 뒤인 n이 삽입 위치 k가 된다.
- **❸** 삽입 위치 k를 빈자리로 만들기 위해 k번 원소부터 마지막 원소까지 한 자리씩 뒤로 이동한다.
- **❹** 자리 이동으로 만든 k번 자리에 삽입 원소 x를 저장한다.

### 2 선형 리스트에서 원소 삭제와 알고리즘

- 원소를 삭제하면 해당 자리가 빈자리가 됨
- 선형 리스트는 연속하여 저장해야 하므로 순차 자료구조 중간에 빈자리가 없어야 함
- 원소를 삭제한 뒤 있는 원소들을 모두 한 자리씩 **앞으로 이동**

### 원소 삭제 과정 (예: 인덱스 2번 자리의 원소 30 삭제)

```
삭제 전: [10][20][30][40][50][60][70]  (인덱스 0~6, n=7)
         ↓ 인덱스 3부터 6까지 한 자리씩 앞으로 이동
삭제 후: [10][20][40][50][60][70]  (인덱스 0~5, n=6)
```

- 이동 횟수 = n−(k+1)+1 = n−k (마지막 원소의 인덱스 − 삭제한 자리의 인덱스)
- 예: 2번 자리 삭제, n=6 → 이동 횟수 = 6−2 = **4회**

> **TIP**: 원소가 n개인 선형 리스트에서 k번 자리에 있는 원소를 삭제하면 (k+1)번 원소부터 마지막 원소인 (n-1)번 원소까지 총 n−(k+1)+1 = n−k개 (전체 원소 개수 − 삭제한 원소의 인덱스 − 1)의 원소를 앞으로 옮겨야 한다.
> 

### 알고리즘 3-2 선형 리스트의 원소 삭제

```
deleteElement(L, n, x)
① for (i ← 0; i≤n; i ← i+1) do {
       if (L[i] == x) then {
           k ← i;
           break;
       }
   }
② for (i ← k; i < n−1; i ← i+1) do   // k+1부터 마지막 원소까지
       L[i] ← L[i+1];                    // 앞으로 한 자리 이동
end deleteElement()
```

- **❶** 선형 리스트 L에서 원소의 크기를 비교하여 삭제 원소 x의 위치 k를 찾는다.
- **❷** (k+1)번 원소부터 마지막 원소까지 한 자리씩 앞으로 이동한다. (k+1)번 자리의 원소를 k번 자리로 이동하면서 덮어쓰기가 되므로 삭제 위치인 k에 있던 원소는 없어진다(삭제된다).

### 📌 예제 3-4 선형 리스트에 원소 삽입하고 삭제하기 (p.134)

**[listS.h]**

```c

#define MAX 10

```

**[listS.c] — 알고리즘 3-1 구현**

```c
#include "listS.h"
int insertElement(int L[], int n, int x) {
    int i, k = 0, move = 0;  // move는 자리 이동 횟수 카운터
    // 원소의 크기를 비교하여 삽입 위치 k 찾기
    for (i = 0; i < n; i++) {
        if (L[i] <= x && x <= L[i+1]) {
            k = i + 1;
            break;
        }
    }
    if (i == n)  // 삽입 원소가 가장 큰 원소인 경우
        k = n;
    // 마지막 원소부터 k+1 원소까지 위로 자리 이동
    for (i = n; i > k; i--) {
        L[i] = L[i-1];
        move++;
    }
    L[k] = x;     // 자리 이동하여 만든 자리 k에 삽입 원소 저장
    return move;
}
```

**[listS.c] — 알고리즘 3-2 구현**

```c
int deleteElement(int L[], int n, int x) {
    int i, k = n, move = 0;  // move는 자리 이동 횟수 카운터
    // 원소의 크기를 비교하여 삭제 위치 k 찾기
    for (i = 0; i < n; i++) {
        if (L[i] == x) {
            k = i;
            break;
        }
    }
    if (i == n) move = n;
    // k+1부터 마지막 원소까지 앞으로 자리 이동
    for (i = k; i < n-1; i++) {
        L[i] = L[i+1];
        move++;
    }
    return move;
}
```

### 1 행렬의 선형 리스트 표현

### 행렬(Matrix)의 개념

- 행과 열로 구성된 자료구조
- **m×n 행렬**: 행 개수가 m개, 열 개수가 n개
- **정방행렬(Square Matrix)**: m과 n이 같은 행렬
- **전치행렬(Transposed Matrix)**: 행렬의 행과 열을 서로 바꿔 구성한 행렬
    - m×n 행렬 A의 모든 원소 (i, j)를 (j, i)로 순서를 교환하면 n×m 행렬인 전치행렬이 됨

### 희소행렬(Sparse Matrix)

- 원소 대부분이 0인 행렬 → 실제로 사용하지 않는 공간이 많아 기억 공간의 활용도가 떨어짐
- m×n 행렬을 그대로 2차원 배열 `A[m][n]`으로 구현하기는 쉽지만 메모리 낭비가 심함

### 희소행렬 B[8][7] 예시

|  | [0] | [1] | [2] | [3] | [4] | [5] | [6] |
| --- | --- | --- | --- | --- | --- | --- | --- |
| [0] | 0 | 0 | 2 | 0 | 0 | 0 | 12 |
| [1] | 0 | 0 | 0 | 0 | 7 | 0 | 0 |
| [2] | 23 | 0 | 0 | 0 | 0 | 0 | 0 |
| [3] | 0 | 0 | 0 | 31 | 0 | 0 | 0 |
| [4] | 0 | 14 | 0 | 0 | 0 | 25 | 0 |
| [5] | 0 | 0 | 0 | 0 | 0 | 0 | 6 |
| [6] | 52 | 0 | 0 | 0 | 0 | 0 | 0 |
| [7] | 0 | 0 | 0 | 0 | 11 | 0 | 0 |
- 배열 원소 56개 중 실제 사용하는 0이 아닌 원소는 **10개** → **46개의 메모리 공간 낭비**

### 희소행렬의 효율적 저장 방법

- 0이 아닌 원소들에 대한 `<행 번호, 열 번호, 값>` 쌍을 구해 2차원 배열에 저장
- **첫 번째 행(0번 행)**: `<전체 행의 개수, 전체 열의 개수, 0이 아닌 원소의 개수>` = `<8, 7, 10>` 저장

**추출된 0이 아닌 원소 순서쌍:**

```
ADT Sparse_Matrix
데이터 : 3원소 쌍 <행 인덱스, 열 인덱스, 원소값>의 집합
// a, b는 희소행렬, c는 행렬, u, v는 행렬의 원소값, i와 j는 행 인덱스와 열 인덱스
연산 : a, b∈Sparse_Matrix; c∈Matrix; u, v∈value; i∈Row; j∈Column;

// m×n의 공백 희소행렬을 만드는 연산
smCreate(m, n) ::= return an empty sparse matrix with m×n;

// 희소행렬 a[j, i]=v를 c[j, i]=v로 전치시킨 전치행렬 c를 구하는 연산
smTranspose(a) ::= return c where c[j, i] = v when a[i, j] = v;

// 차수가 같은 희소행렬 a와 b를 합한 행렬 c를 구하는 연산
smAdd(a, b) ::= if (a.dimension = b.dimension)
                    then return c where c[i, j] = v + u where a[i,j] = v and b[i, j] = u
                    else return error;

// 희소행렬 a의 열(n)과 희소행렬 b의 행(m) 개수가 같은 경우에 두 행렬의 곱을 구하는 연산
smMulti(a, b) ::= if (a.n = b.m) then return c where c[i, j] = a[i, k] × b[k, j];
                  else return error;
End Sparse_Matrix
```

### 알고리즘 3-3 희소행렬의 전치 연산

```
smTranspose(a[])
    m ← a[0, 0];          // 희소행렬 a의 행 수
    n ← a[0, 1];          // 희소행렬 a의 열 수
    v ← a[0, 2];          // 희소행렬 a에서 0이 아닌 원소 수
    b[0, 0] ← n;          // 전치행렬 b의 행 수 저장
    b[0, 1] ← m;          // 전치행렬 b의 열 수 저장
    b[0, 2] ← v;          // 전치행렬 b의 원소 수 저장
    if (v > 0) then {      // 0이 아닌 원소가 있는 경우에만 전치 연산 수행
        p ← 1;
        for (i ← 0; i < n; i ← i+1) do {     // 희소행렬 a의 열별로 전치 반복 수행
            for (j ← 1; j ← v; j ← j+1) do { // 0이 아닌 원소 수에 대해서만 반복 수행
                if (a[j, 1] == i) then {        // 현재의 열에 속하는 원소가 있으면 b[]에 삽입
                    b[p, 0] ← a[j, 1];
                    b[p, 1] ← a[j, 0];
                    b[p, 2] ← a[j, 2];
                    p ← p + 1;
                }
            }
        }
    }
    return b[];
end smTranspose()
```

```c
#include "smTranspose.h"
void smTranspose(term a[], term b[]) {
    int m, n, v, i, j, p;
    m = a[0].row;              // 희소행렬 a의 행 수
    n = a[0].col;              // 희소행렬 a의 열 수
    v = a[0].value;            // 희소행렬 a에서 0이 아닌 원소 수
    b[0].row = n;              // 전치행렬 b의 행 수 저장
    b[0].col = m;              // 전치행렬 b의 열 수 저장
    b[0].value = v;            // 전치행렬 b의 원소 수 저장
    if (v > 0) {               // 0이 아닌 원소가 있는 경우에만 전치 연산 수행
        p = 1;
        for (i = 0; i < n; i++) {      // 희소행렬 a의 열별로 전치 반복 수행
            for (j = 1; j <= v; j++) { // 0이 아닌 원소 수에 대해서만 반복 수행
                if (a[j].col == i) {   // 현재의 열에 속하는 원소가 있으면 b[]에 삽입
                    b[p].row = a[j].col;
                    b[p].col = a[j].row;
                    b[p].value = a[j].value;
                    p++;
                }
            }
        }
    }
    return b[];
}
```

### 2 다항식의 선형 리스트 표현

### 다항식의 개념

- `ax^e` 형식의 항들의 합으로 구성된 식

| 기호 | 의미 |
| --- | --- |
| **a** | 계수 (Coefficient) |
| **x** | 변수 (Variable) |
| **e** | 지수 (Exponent) |
- 지수가 높은 항부터 낮은 항의 순서로 항을 나열
- 가장 큰 지수 → **다항식의 차수**
- 다항식의 항의 최대 개수 = **(차수 + 1)개**

**n차 다항식 P(x):**

```
P(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x¹ + a₀x⁰
```

- 배열 P에서 인덱스 i는 지수가 (n-i)인 항에 대응되는 배열 원소를 의미
- P[i]의 값은 지수가 (n-i)인 항의 계수

**예: A(x) = 4x³ + 3x² + 2**

| 인덱스 | [0] | [1] | [2] | [3] |
| --- | --- | --- | --- | --- |
| A | 4 | 3 | 0 | 2 |

> A[2] = 0 → x¹항이 없다는 것이므로 0x¹항인 것이다.
> 

### 희소 다항식의 문제

- 예: `B(x) = 3x¹⁰⁰⁰ + x + 4` → 지수는 1000이지만 항의 개수는 3개뿐인 희소 다항식
- 배열 크기 1001인 배열을 사용하는데, 실제 사용하는 것은 3개 → **998개의 배열 원소 공간 낭비**

**희소 다항식의 저장 방식 비교:**

| 방법 | 설명 |
| --- | --- |
| (a) 1차원 배열 이용 | 지수 순서대로 인덱스에 계수 저장. 차수가 크고 항이 적으면 낭비 심함 |
| (b) 2차원 배열 이용 | `<지수, 계수>` 쌍을 2차원 배열에 저장. 0번 열에 지수, 1번 열에 계수. 희소 다항식에 적합 |

**희소 다항식 B(x) = 3x¹⁰⁰⁰ + x + 4의 2차원 배열 저장:**

| [0] | [1] |
| --- | --- |
| 1000 | 3 |
| 1 | 1 |
| 0 | 4 |

### ADT 3-2 다항식의 추상 자료형

```
ADT Polynomial
데이터 : 지수(e) - 계수(a)의 순서쌍 <e, a>의 집합으로 표현된 다항식
         = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x¹ + a₀x⁰ (eₙ은 음이 아닌 정수)
// p, p1, p2는 다항식, a는 계수, e는 지수
연산 : p, p1, p2 ∈ Polynomial; a ∈ Coefficient; e ∈ Exponent;

// 공백 다항식 p(x) = 0을 만드는 연산
zeroP()    ::= return polynomial p(x) = 0;

// 다항식 p가 0인지 검사하여 0이면 true를 반환하는 연산
isZeroP(p) ::= if (p) then false
               else return true;

// 다항식 p에서 지수가 e인 항의 계수 a를 구하는 연산
coef(p, e) ::= if (<e, a> ∈ p) then return a
               else return 0;

// 다항식 p에서 최대 지수를 구하는 연산
maxExp(p)  ::= return max(p.Exponent);

// 다항식 p에서 지수가 e인 항이 없는 경우에 새로운 항 <e, a>를 추가하는 연산
addTerm(p, a, e) ::= if (e ∈ p.Exponent) then return error
                     else return p after inserting the term <e, a>;

// 다항식 p에서 지수가 e인 항 <e, a>를 삭제하는 연산
delTerm(p, e) ::= if (e ∈ p.Exponent) then return p after removing the term <e, a>
                  else return error;

// 다항식 p의 모든 항에 ax^e항을 곱하는 연산
multTerm(p, a, e) ::= return (p + axᵉ);

// 다항식 p1과 p2의 합을 구하는 연산
addPoly(p1, p2) ::= return (p1 + p2);

// 다항식 p1과 p2의 곱을 구하는 연산
multPoly(p1, p2) ::= return (p1 × p2);
End Polynomial
```

### 다항식의 덧셈 연산

**예: A(x) + B(x) = C(x)**

```
A(x) =          4x³ + 3x² +       5x
B(x) = 3x⁴ +    x³ +       2x + 1
C(x) = 3x⁴ + (4+1)x³ + 3x² + (5+2)x + 1
     = 3x⁴ +    5x³ + 3x² +   7x + 1
```

### 알고리즘 3-4 순차 리스트를 이용한 다항식의 덧셈 연산

```
addPoly(A, B)
// 주어진 두 다항식 A와 B를 더하여 결과 다항식 C를 반환하는 알고리즘
C ← zeroP();
while (not isZeroP(A) and not isZeroP(B)) do {
    case {
        maxExp(A) < maxExp(B) :
            C ← addTerm(C, coef(B, maxExp(B)), maxExp(B));
            B ← delTerm(B, maxExp(B));
        maxExp(A) == maxExp(B) :
            sum ← coef(A, maxExp(A)) + coef(B, maxExp(B));
            if (sum≠0) then C ← addTerm(C, sum, maxExp(A));
            A ← delTerm(A, maxExp(A));
            B ← delTerm(B, maxExp(B));
        maxExp(A) > maxExp(B) :
            C ← addTerm(C, coef(A, maxExp(A)), maxExp(A));
            A ← delTerm(A, maxExp(A));
    }
}
if (not isZeroP(A)) then A의 나머지 항들을 C에 복사
else if (not isZeroP(B)) then B의 나머지 항들을 C에 복사
return C;
end addPoly()
```

- **알고리즘 설명**: 다항식 A, B의 항을 하나씩 검사하여 지수가 같으면 계수를 더해서 만든 항을 다항식 C에 추가(addTerm()), 지수가 다르면 둘 중에서 지수가 큰 항을 다항식 C에 추가(addTerm())하는 과정을 마지막 항까지 반복하여 덧셈 결과 다항식 C를 완성

### 📌 예제 3-6 순차 리스트를 이용해 다항식 덧셈하기 (p.145)

**[addPoly.h]**

```c
#pragma once
#define MAX(a,b) ((a>b)?a:b)
#define MAX_DEGREE 50

typedef struct {               // 구조체 polynomial 정의
    int degree;                // 다항식의 차수를 저장할 변수
    float coef[MAX_DEGREE];   // 다항식의 각 항의 계수를 저장할 1차원 배열
} polynomial;

polynomial addPoly(polynomial A, polynomial B);
void printPoly(polynomial P);
```

**[addPoly.c]**

```c
#include "addPoly.h"
polynomial addPoly(polynomial A, polynomial B) {
    polynomial C;  // 다항식 덧셈의 결과 다 항식을 저장할 polynomial 구조체 변수 선언
    int A_index = 0, B_index = 0, C_index = 0;
    int A_degree = A.degree, B_degree = B.degree;
    C.degree = MAX(A.degree, B.degree);

    while (A_index <= A.degree && B_index <= B.degree) {
        if (A_degree > B_degree) {           // 10~13행
            C.coef[C_index++] = A.coef[A_index++];
            A_degree--;
        } else if (A_degree == B_degree) {   // 14~18행
            C.coef[C_index++] = A.coef[A_index++] + B.coef[B_index++];
            A_degree--;
            B_degree--;
        } else {                              // 19~22행
            C.coef[C_index++] = B.coef[B_index++];
            B_degree--;
        }
    }
    return C;  // 다항식 덧셈의 결과 다항식 C를 반환
}
```

**코드 설명:**

- **9행**: 다항식 A에서 현재 처리 중인 항의 인덱스가 다항식 A의 차수 이내이고 다항식 B에서 현재 처리 중인 항의 인덱스가 다항식 B의 차수 이내인 동안, 즉 두 다항식에서 처리할 항이 남아 있는 동안 반복 수행
- **10~13행**: 다항식 A에서 현재 처리 중인 항의 지수가 다항식 B에서 현재 처리 중인 항의 지수보다 큰 경우, 다항식 A의 현재 항의 계수를 다항식 C의 현재 항의 계수로 저장. 처리가 끝난 다항식 A와 C는 다음에 처리할 항을 준비
- **14~18행**: 두 항의 지수가 같은 경우, 두 항의 계수를 더하여 다항식 C의 현재 항의 계수로 저장
- **19~22행**: 다항식 A에서 현재 처리 중인 항의 지수가 다항식 B에서 현재 처리 중인 항의 지수보다 작은 경우, 다항식 B의 현재 항의 계수를 다항식 C의 현재 항의 계수로 저장

# Chapter 04 - 연결 자료구조와 연결 리스트

## Section 01 - 연결 자료구조와 연결 리스트의 이해

### 1. 연결 자료구조의 개념

- **순차 자료구조**의 단점:
    - 원소 위치를 찾아 액세스하기 쉽지 않음
    - 삽입/삭제 시 물리적 위치를 유지하기 위해 원소를 옮기는 추가 작업 필요 → 시간 낭비
    - 원소 개수가 많고 삽입/삭제 연산이 많을 경우 오버헤드 다수 발생
    - 배열을 이용하므로 배열이 갖는 메모리 사용의 비효율성 문제 내포
- **연결 자료구조 (Linked Data Structure)** 또는 **비순차 자료구조 (Nonsequential Data Structure)**:
    - 원소의 논리적 순서와 물리적 순서가 일치하지 않아도 됨
    - 각 원소에 저장된 **다음 원소의 주소(링크)**에 의해 순서가 연결
    - 물리적인 순서를 맞추기 위한 오버헤드 발생 없음

> 💡 비유: 순차 자료구조 = 이불과 퀼트 이불(고정 크기 메모리), 연결 자료구조 = 소시지와 줄줄이 소시지(작은 공간을 여러 개 연결)
> 

---

### 2. 노드(Node)

- 연결 자료구조의 원소 = **노드(Node)**
- 노드 구성:
    - **데이터 필드(Data Field)**: 원소값 저장
    - **링크 필드(Link Field)**: 다음 노드의 주소 저장 (포인터 변수 사용)

```
[ data | link → ]
```

- 링크 필드는 포인터 또는 참조(Reference)라고도 함
- **앞으로 연결 자료구조 방식으로 구현 = 포인터를 이용한 구현**

---

### 3. 순차 자료구조 vs 연결 자료구조 비교 (표 4-1)

| 구분 | 순차 자료구조 | 연결 자료구조 |
| --- | --- | --- |
| 메모리 저장 방식 | 필요한 전체 메모리 크기를 계산하여 할당, 메모리의 시작 위치(=첫 번째 배치)부터 순서대로 저장 | 노드 단위로 메모리가 할당되며, 저장 위치의 순서와 상관없이 노드의 링크 필드에 다음 자료의 주소를 저장 |
| 연산 특징 | 삽입·삭제 연산 후에도 빈자리 없이 자료가 순서대로 연속 저장되며, 변경된 논리적인 순서와 저장된 물리적인 순서가 일치 | 삽입·삭제 연산 후 논리적인 순서가 변경되어도 물리적 위치는 변경되지 않음 |
| 프로그램 기법 | 배열을 이용한 구현 | 포인터를 이용한 구현 |

---

### 4. 연결 리스트의 이해

**기차놀이 비유:**

- 아이들이 이름표를 들고 이름표대로 한쪽으로만 연결 = 인간 기차
- 각 아이(노드)의 **이름표 = 데이터 필드**, **다음 사람 이름표 = 링크 필드**

```
[ 승희 | 상원 ] → [ 상원 | 수영 ] → [ 수영 | NULL ]
```

- **선형 리스트 week** = (월, 화, 수, 목, 금, 토, 일)
    - 순차 리스트: 배열 원소 7개 사용, 연속적인 순차 구조로 메모리 표현
    - 연결 리스트: 노드 7개와 시작 포인터 `week` 사용, 비연속적인 연결 구조로 메모리 표현

---

### 5. 연결 리스트의 물리적 구조 (그림 4-6)

```
week → [100번지]
100번지: 월 | 160  →  160번지: 화 | 120  →  120번지: 수 | 130  → ...  →  175번지: 일 | NULL
```

- `week.data` = 100번지 노드의 데이터 = '월'
- `week.link` = 100번지 노드의 링크 = 160
- `week.link.data` = 160번지 노드의 데이터 = '화'
- 노드 접근: **점(.) 연산자** 사용

---

### 6. 노드의 구조체 정의 (C언어)

```c
typedef struct Node {
    char data[4];
    struct Node* link;
};
```

- 링크 필드의 자료형: **struct Node**(같은 구조의 다음 노드를 가리키는 포인터)

---

### 7. 연결 리스트의 종류

연결 방식에 따라:

1. **단순 연결 리스트** (Singly Linked List)
2. **원형 연결 리스트** (Circular Linked List)
3. **이중 연결 리스트** (Doubly Linked List)
4. **이중 원형 연결 리스트** (Doubly Circular Linked List)

## Section 02 - 단순 연결 리스트

### 1. 단순 연결 리스트의 개념

- 노드의 **링크 필드가 하나**이며, 다음 노드와 연결되는 구조
- = 연결 리스트 = 선형 연결 리스트 (Linear Linked List) = 단순 연결 선형 리스트 (Singly Linked Linear List)
- 마지막 노드의 링크 필드 = **NULL**
- **공백 연결 리스트**: 포인터 변수에 NULL 저장

---

### 2. 단순 연결 리스트에서의 삽입 연산

### 삽입 방법 (순서 중요!)

> 🔑 기차놀이 비유: 승희-상원-수영 사이에 철이를 끼우는 과정
> 

① 앞사람에게 이름표 받아오기 (앞 노드의 링크값 획득)

② 앞사람에게 자기 이름표 주기 (새 노드가 앞 노드에게 자신의 이름표 전달)

③ 이름표대로 연결하기

**정리:**

1. 삽입할 노드를 준비한다
2. 새 노드의 데이터 필드에 값을 저장한다
3. 새 노드의 링크값을 지정한다
4. 리스트의 앞 노드에 새 노드를 연결한다

> ✅ 순차 리스트와 달리 **물리적 순서를 유지하기 위해 원소를 이동시키지 않아도 됨** → 링크 필드의 포인터값에 대한 연산만으로 삽입 가능
> 

---

### 3. 단순 연결 리스트에서의 삭제 연산

**삭제 방법:**

1. 삭제할 노드의 앞 노드를 찾는다
2. 앞 노드에 삭제할 노드의 링크 필드값을 저장한다
3. 삭제한 노드의 앞 노드와 삭제한 노드의 다음 노드를 연결한다

> ✅ 삭제 연산에서도 원소들이 물리적으로 이동하지 않음
> 

---

### 4. 단순 연결 리스트의 알고리즘과 프로그램

### 삽입 알고리즘 분류 (삽입 위치에 따라 3가지)

---

### 알고리즘 4-1: 리스트의 첫 번째 노드 삽입

```
insertFirstNode(L, x)
    ① new ← getNode()
    ② new.data ← x
    ③ new.link ← L
    ④ L ← new
end insertFirstNode()
```

**동작 설명:**

1. `new ← getNode()` : 새 노드 메모리 할당, 포인터 new 설정
2. `new.data ← x` : 데이터 필드에 x 저장
3. `new.link ← L` : 리스트의 첫 번째 노드 주소(L, 100)를 new의 링크 필드에 저장 → new가 100번지의 첫 번째 노드로 연결
4. `L ← new` : 리스트의 첫 번째 노드 주소를 new 노드의 주소(700)로 저장 → 포인터 L을 새 노드(리스트의 첫 번째 노드)로 연결

---

### 알고리즘 4-2: 리스트 중간에 노드 삽입

```
insertMiddleNode(L, pre, x)
    ① new ← getNode()
    ② new.data ← x
    ③ if (L = NULL) then {
        ③-① L ← new
        ③-② new.link ← NULL
    }
    else {
        ④-① new.link ← pre.link
        ④-② pre.link ← new
    }
end insertMiddleNode()
```

- `pre`: 삽입할 위치 앞에 있는 선행자 노드를 알려주는 포인터
- 공백 리스트인 경우와 공백이 아닌 경우로 구분

**공백이 아닌 경우 동작:**

1. `new.link ← pre.link` : 노드 pre의 다음 노드로 new를 연결 (pre.link=200을 new의 링크에 저장)
2. `pre.link ← new` : 포인터 new의 값(700)을 노드 pre의 링크에 저장 → pre가 new로 연결되도록

---

### 알고리즘 4-3: 리스트 마지막에 노드 삽입

```
insertLastNode(L, x)
    ① new ← getNode()
    ② new.data ← x
    ③ new.link ← NULL
    if (L = NULL) then {
        ④-① L ← new
        return
    }
    ③-② temp ← L
    while (temp.link ≠ NULL) do
        ③-③ temp ← temp.link
    ③-④ temp.link ← new
end insertLastNode()
```

- 마지막 노드를 찾기 위해 **임시 포인터 temp** 사용
- `while (temp.link ≠ NULL)`: 링크 필드를 따라 이동
- 마지막 노드 도달 시 temp.link에 new 연결

---

### 알고리즘 4-4: 단순 연결 리스트의 노드 삭제

```
deleteNode(L, pre)
    ① if (L = NULL) then error
    else {
        ②-① old ← pre.link
        ②-② if (old = NULL) then return
        ②-③ pre.link ← old.link
        ②-④ returnNode(old)
    }
end deleteNode()
```

**동작 설명:**

1. `old ← pre.link` : 삭제할 노드를 old로 지정
2. `if (old = NULL) then return` : pre가 마지막 노드이면 삭제할 노드 없음 → 종료
3. `pre.link ← old.link` : 삭제할 노드 old의 다음 노드를 pre의 다음 노드로 연결
4. `returnNode(old)` : 삭제한 노드 old의 메모리 반환

---

### 알고리즘 4-5: 단순 연결 리스트의 노드 탐색

```
searchNode(L, x)
    ① temp ← L
    while (temp ≠ NULL) do {
        ②-① if (temp.data == x) then return temp
        ②-② else temp ← temp.link
    }
    ③ return temp
end searchNode()
```

- 리스트의 처음부터 하나씩 순회하면서 데이터 필드값과 x를 비교
- 탐색 성공: 해당 노드의 주소 반환
- 탐색 실패: NULL 반환

---

### 5. 단순 연결 리스트 프로그램 1 (예제 4-1)

**파일 구조:**

`[InsertLinkedList.h]`

```c
#pragma once
// 단순 연결 리스트의 노드 구조를 구조체로 정의
typedef struct ListNode {
    char data[4];
    struct ListNode* link;
} listNode;

// 리스트 시작을 나타내는 head 노드를 구조체로 정의
typedef struct {
    listNode* head;
} linkedList_h;

linkedList_h* createLinkedList_h(void);
void freeLinkedList_h(linkedList_h* L);
```

`[InsertLinkedList.c]` 주요 구현:

```c
// 공백 연결 리스트를 생성하는 연산
linkedList_h* createLinkedList_h(void) {
    linkedList_h* L;
    L = (linkedList_h*)malloc(sizeof(linkedList_h));
    L->head = NULL;    // 공백 리스트이므로 NULL로 설정
    return L;
}

// 첫 번째 노드로 삽입하는 연산
void insertFirstNode(linkedList_h *L, char *x) {
    listNode* newNode;
    newNode = (listNode*)malloc(sizeof(listNode));  // 삽입할 새 노드 할당
    strcpy(newNode->data, x);                        // 새 노드의 데이터 필드에 x 저장
    newNode->link = L->head;
    L->head = newNode;
}

// 노드를 pre 뒤에 삽입하는 연산
void insertMiddleNode(linkedList_h *L, listNode* pre, char *x) {
    listNode* newNode;
    newNode = (listNode*)malloc(sizeof(listNode));
    strcpy(newNode->data, x);
    if (L->head == NULL) {            // 공백 리스트인 경우
        newNode->link = NULL;
        L->head = newNode;
    }
    else if (pre == NULL) {           // 삽입 위치를 지정하는 포인터 pre가 NULL인 경우
        newNode->link = L->head;      // 새 노드를 첫 번째 노드로 삽입
        L->head = newNode;
    }
    else {
        newNode->link = pre->link;    // 포인터 pre의 노드 뒤에 새 노드 연결
        pre->link = newNode;
    }
}

// 마지막 노드로 삽입하는 연산
void insertLastNode(linkedList_h *L, char* x) {
    listNode* newNode;
    listNode* temp;
    newNode = (listNode*)malloc(sizeof(listNode));
    strcpy(newNode->data, x);
    newNode->link = NULL;
    if (L->head == NULL) {    // 현재 리스트가 공백인 경우
        L->head = newNode;    // 새 노드를 리스트의 시작 노드로 연결
        return;
    }
    // 현재 리스트가 공백이 아닌 경우
    temp = L->head;
    while (temp->link != NULL) temp = temp->link;  // 현재 리스트의 마지막 노드를 찾음
    temp->link = newNode;    // 새 노드를 마지막 노드(temp)의 다음 노드로 연결
}
```

### 6. 단순 연결 리스트 프로그램 2 (예제 4-2)

- 예제 4-1에 **삭제 연산**, **탐색 연산**, **역순(reverse) 연산** 추가

```c
// 리스트에서 노드 p를 삭제하는 연산
void deleteNode(linkedList_h *L, listNode* p) {
    listNode* pre;
    if (L->head == NULL) return;             // 공백 리스트라면 삭제 연산 종단
    if (L->head->link == NULL) {             // 리스트에 노드가 한 개만 있는 경우
        // 첫 번째 노드를 메모리에서 해제하고
        L->head = NULL;                       // 리스트 시작 포인터를 NULL로 설정
        return;
    }
    else if (p == NULL) return;              // 삭제할 노드가 없다면 삭제 연산 종단
    else {
        pre = L->head;
        while (pre->link != p) {
            pre = pre->link;
        }
        pre->link = p->link;    // 삭제할 노드 p의 선행자 노드와 다음 노드를 연결
        free(p);                 // 삭제 노드의 메모리 해제
    }
}

// 리스트에서 x 노드를 탐색하는 연산
listNode* searchNode(linkedList_h *L, char* x) {
    listNode *temp;
    temp = L->head;
    while (temp != NULL) {
        if (strcmp(temp->data, x) == 0) return temp;
        else temp = temp->link;
    }
    return temp;
}

// 리스트의 노드 순서를 역순으로 바꾸는 연산 (추가 연산)
void reverse(linkedList_h * L) {
    listNode* p;
    listNode* q;
    listNode* r;

    p = L->head;        // 포인터 p를 첫 번째 노드에 설정
    q = NULL;
    r = NULL;

    // 노드 간의 연결을 바꿈
    while (p != NULL) {
        r = q;
        q = p;
        p = p->link;
        q->link = r;
    }
    L->head = q;
}
```

**reverse 함수 동작 (3개 노드 리스트 기준):**

| 단계 | p | q | r | 변화 |
| --- | --- | --- | --- | --- |
| 초기 | 100 | NULL | NULL | 시작 상태 |
| 1회 | 200 | 100 | NULL | 월↔NULL, 수↔월 순서 바뀌기 시작 |
| 2회 | 300 | 200 | 100 | 수↔월 순서가 바뀜 |
| 3회 | NULL | 300 | 200 | 금→수→월→NULL로 역순 완성 |

→ 마지막으로 `L->head = q`를 수행하여 리스트의 마지막 노드 q를 시작 노드로 변경

## Section 03 - 원형 연결 리스트

### 1. 원형 연결 리스트의 개념

- 단순 연결 리스트에서 **마지막 노드의 링크 필드를 첫 번째 노드**를 가리키게 하여 리스트 구조를 원형으로 만든 것
- = **원형 연결 리스트 (Circular Linked List)**
- 단순 연결 리스트는 마지막 노드에서 링크를 따라 이동하면 순회가 끝나지만, 원형 연결 리스트는 링크를 따라 계속 순회 가능

```
[100번지] → [200번지] → [300번지] → [400번지] → (100번지로 돌아감)
```

---

### 2. 원형 연결 리스트의 알고리즘

### 알고리즘 4-6: 원형 연결 리스트의 첫 번째 노드 삽입

```
insertFirstNode(CL, x)
    new ← getNode()
    new.data ← x
    if (CL == NULL) then {
        ①-① CL ← new
        ①-② new.link ← new
    }
    else {
        ②-① temp ← CL
        while (temp.link ≠ CL) do
            ②-② temp ← temp.link
        ②-③ new.link ← temp.link
        ②-④ temp.link ← new
        ②-⑤ CL ← new
    }
end insertFirstNode()
```

- **단순 연결 리스트에서 첫 번째 노드로 삽입하는 알고리즘 + 마지막 노드로 삽입하는 알고리즘을 혼합한 형태**

**공백 리스트인 경우:**

- `CL ← new`: 새 노드의 주소를 포인터 CL에 저장 → new가 리스트의 첫 번째 노드이자 마지막 노드
- `new.link ← new`: 새 노드의 링크 필드에 자기 자신의 주소를 저장 → 자기 자신으로 연결

**공백이 아닌 경우:**

1. `temp ← CL`: 첫 번째 노드의 주소를 임시 포인터 temp에 설정
2. `while (temp.link ≠ CL)`: temp를 링크를 따라 마지막 노드까지 이동
3. `new.link ← temp.link`: 리스트의 마지막 노드의 링크값을 new의 링크에 저장 → new가 노드 temp의 다음 노드인 첫 번째 노드와 연결
4. `temp.link ← new`: 포인터 new의 값(700)을 포인터 temp가 가리키는 마지막 노드의 링크에 저장 → 마지막 노드가 new로 원형 연결
5. `CL ← new`: 포인터 new의 값(700)을 리스트 시작 포인터 CL에 설정 → new가 리스트의 첫 번째 노드

---

### 알고리즘 4-7: 원형 연결 리스트의 중간 노드 삽입

```
insertMiddleNode(CL, pre, x)
    new ← getNode()
    new.data ← x
    if (CL == NULL) then {
        CL ← new
        new.link ← new
    }
    else {
        ②-① new.link ← pre.link
        ②-② pre.link ← new
    }
end insertMiddleNode()
```

**공백이 아닌 경우:**

1. `new.link ← pre.link`: 노드 pre의 다음 노드(pre.link, 300번지 노드)를 new의 다음 노드(new.link)로 연결
2. `pre.link ← new`: 포인터 new의 값(삽입할 새 노드의 주소, 700)을 노드 pre의 링크에 저장 → pre가 new로 연결

---

### 알고리즘 4-8: 원형 연결 리스트의 노드 삭제

```
deleteNode(CL, pre)
    if (CL == NULL) then error
    else {
        ① old ← pre.link
        ② pre.link ← old.link
        ③ if (old == CL) then
            ③-① CL ← old.link
        ④ returnNode(old)
    }
end deleteNode()
```

**동작 설명:**

1. `old ← pre.link`: 노드 pre의 다음 노드(pre.link, 300번지)를 삭제할 노드에 대한 포인터 old로 지정
2. `pre.link ← old.link`: 삭제할 노드 old의 다음 노드(old.link, 400번지)를 노드 pre의 다음 노드(pre.link)로 지정
3. `if (old == CL) then`: 삭제할 노드 old가 리스트의 첫 번째 노드인지 확인
    - 첫 번째 노드를 삭제하는 경우: 리스트 포인터 CL에 대한 연결 처리 추가 필요
    - `CL ← old.link`: 노드 old의 링크값(200)을 리스트 포인터 CL에 저장 → 두 번째 노드가 리스트의 첫 번째 노드가 되도록 조정
4. `returnNode(old)`: 삭제한 노드 old의 메모리 반환

---

### 3. 원형 연결 리스트의 프로그램 (예제 4-3)

`[CircularLinkedList.h]`

```c
#pragma once
// 원형 연결 리스트의 노드 구조를 구조체로 정의
typedef struct ListNode {
    char data[4];
    struct ListNode* link;
} listNode;

typedef struct {
    listNode* head;
} linkedList_h;

linkedList_h* createLinkedList_h(void);
void printList(linkedList_h* CL);
void insertFirstNode(linkedList_h* CL, char* x);
void insertMiddleNode(linkedList_h* CL, listNode* pre, char* x);
void deleteNode(linkedList_h* CL, listNode* old);
listNode* searchNode(linkedList_h* CL, char* x);
```

`[CircularLinkedList.c]` 주요 구현:

```c
// 연결 리스트를 순서대로 출력하는 연산
void printList(linkedList_h* CL) {
    listNode* p;
    printf(" CL = (");
    p = CL->head;
    if (p == NULL) {
        printf(") \n");  return;
    }
    do {
        printf("%s", p->data);
        p = p->link;
        if (p != CL->head) printf(", ");
    } while (p != CL->head);
    printf(") \n");
}

// 첫 번째 노드 삽입 연산
void insertFirstNode(linkedList_h *CL, char *x) {
    listNode* newNode, *temp;
    newNode = (listNode*)malloc(sizeof(listNode));  // 삽입할 새 노드 할당
    strcpy(newNode->data, x);
    if (CL->head == NULL) {         // 원형 연결 리스트가 공백인 경우
        CL->head = newNode;         // 새 노드들을 리스트의 시작 노드로 연결
        newNode->link = newNode;
    }
    else {                          // 원형 연결 리스트가 공백이 아닌 경우
        temp = CL->head;
        while (temp->link != CL->head)
            temp = temp->link;
        newNode->link = temp->link;
        temp->link = newNode;       // 마지막 노드를 첫 번째 노드인 new와 원형 연결
        CL->head = newNode;
    }
}

// pre 뒤에 노드를 삽입하는 연산
void insertMiddleNode(linkedList_h *CL, listNode *pre, char *x) {
    listNode* newNode;
    newNode = (listNode*)malloc(sizeof(listNode));
    strcpy(newNode->data, x);
    if (CL->head == NULL) {
        CL->head = newNode;
        newNode->link = newNode;
    }
    else {
        newNode->link = pre->link;
        pre->link = newNode;
    }
}
```

## 핵심 정리

### 연결 리스트 종류별 특징 요약

| 종류 | 특징 | 마지막 노드의 링크 |
| --- | --- | --- |
| 단순 연결 리스트 | 링크 필드 1개, 한 방향 연결 | NULL |
| 원형 연결 리스트 | 마지막 노드가 첫 번째 노드를 가리킴 | 첫 번째 노드 주소 |
| 이중 연결 리스트 | 링크 필드 2개 (앞/뒤 방향) | NULL |
| 이중 원형 연결 리스트 | 이중 연결 + 원형 구조 | 첫 번째 노드 주소 |

### 삽입/삭제 연산 핵심 원칙

- **삽입**: 새 노드의 링크를 먼저 설정한 뒤, 앞 노드의 링크를 변경
- **삭제**: 앞 노드의 링크를 삭제 노드의 다음 노드로 연결 → 메모리 반환
- **물리적 이동 불필요**: 링크 포인터값 변경만으로 모든 연산 수행

### 자주 사용되는 포인터 변수

| 포인터 | 역할 |
| --- | --- |
| `L` 또는 `CL` | 리스트의 시작(첫 번째 노드)을 가리키는 포인터 |
| `new` | 새로 삽입할 노드를 가리키는 포인터 |
| `pre` | 삽입/삭제 위치의 선행자(앞) 노드를 가리키는 포인터 |
| `old` | 삭제할 노드를 가리키는 포인터 |
| `temp` | 리스트를 순회할 때 사용하는 임시 포인터 |
| `p`, `q`, `r` | 역순 연산 등 복잡한 연산에서 사용하는 보조 포인터 |

---

## Section 03 - 원형 연결 리스트 (이어서)

### 4. 원형 연결 리스트 프로그램 주요 코드 (예제 4-3)

`[CircularLinkedList.c]` 삭제 연산:

```c
// 원형 연결 리스트의 pre 뒤에 있는 노드 old를 삭제하는 연산  [알고리즘 4-8 구현]
void deleteNode(linkedList_h* CL, listNode* old) {
    listNode* pre;
    if (CL->head == NULL) return;          // 공백 리스트인 경우 삭제 연산 종단
    if (CL->head == CL->head) {            // 리스트에 노드가 한 개만 있는 경우
        free(CL->head);                    // 첫 번째 노드의 메모리를 해제하고
        CL->head = NULL;                   // 리스트 시작 포인터를 NULL로 설정
        return;
    }
    else if (old == NULL) return;          // 삭제할 노드가 없는 경우 삭제 연산 종단
    else {
        pre = CL->head;
        while (pre->link != old) {         // 선행자 노드를 포인터 pre를 이용해 찾음
            pre = pre->link;
        }
        pre->link = old->link;
        if (old == CL->head)
            CL->head = old->link;          // 삭제 노드의 메모리를 해제
        free(old);
    }
}
```

탐색 연산:

```c
// 원형 연결 리스트에서 x 노드를 탐색하는 연산
listNode* searchNode(linkedList_h* CL, char* x) {
    listNode *temp;
    temp = CL->head;
    if (temp == NULL) return NULL;
    do {
        if (strcmp(temp->data, x) == 0) return temp;
        else temp = temp->link;
    } while (temp != CL->head);
    return NULL;
}
```

**실행 결과 예시:**

```
CL = (월, 수, 금)
(5) 원형 연결 리스트에서 [수] 노드 삭제하기!
```

## Section 04 - 이중 연결 리스트

### 1. 이중 연결 리스트의 개념

- **단순 연결 리스트**의 문제: 선행 노드로 접근하기 어려움
- **원형 연결 리스트**의 문제: 현재 노드 바로 이전 노드로 접근하려면 전체 리스트를 한 바퀴 순회해야 함
- → 이러한 문제를 개선하여 **양쪽 방향으로 순회할 수 있도록 노드를 연결한 리스트**
- = **이중 연결 리스트 (Doubly Linked List)**

### 노드 구조

- 링크 필드 **두 개** + 데이터 필드 **한 개**
- **llink (Left Link)**: 왼쪽(이전) 노드와 연결하는 포인터
- **rlink (Right Link)**: 오른쪽(다음) 노드와 연결하는 포인터

```
[ llink | data | rlink ]
```

```c
typedef struct Dnode {
    struct Dnode *llink;
    char data[5];
    struct Dnode *rlink;
}
```

### 핵심 성질

이중 연결 리스트에서 **첫 번째와 마지막 노드가 아닌 임의의 노드 p**에 대해:

```
p = p.llink.rlink = p.rlink.llink
```

- 예) 포인터 p가 '수' 노드를 가리킬 때:
    - `p.llink` = '월' 노드
    - `p.llink.rlink` = '월' 노드의 오른쪽 노드 = 다시 '수' 노드
    - `p.rlink` = '금' 노드
    - `p.rlink.llink` = '금' 노드의 왼쪽 노드 = 다시 '수' 노드

### 이중 원형 연결 리스트

이중 연결 리스트를 원형으로 구성하면 **이중 원형 연결 리스트**가 된다.

```
[100번지] ←→ [200번지] ←→ [300번지]
  (100 llink=300)          (300 rlink=100)  ← 원형 구조
```

> 💡 비유: 단방향 기차놀이(한쪽만 이름표) vs 양방향 기차놀이(양쪽에 이름표)
> 

---

### 2. 이중 연결 리스트의 알고리즘

### 이중 연결 리스트에 노드를 삽입하는 방법 (그림 4-30)

> 💡 기차놀이 비유: 승희-상원-수영 사이에 철이를 끼우는 과정 (양방향)
> 

① 철이의 왼쪽이 되어야 하는 승희는 오른손에 쥐고 있던 '상원' 이름표를 철이 오른손에 준다

② 철이의 오른쪽이 되어야 하는 상원이는 왼손에 쥐고 있던 '승희' 이름표를 철이 왼손에 준다

③ 대신 철이는 '철이' 이름표를 승희에게 준다

④ 대신 철이는 '철이' 이름표를 상원이에게 준다

⑤ 이름표대로 연결 → 양방향 기차 완성

**정리:**

1. 삽입할 노드를 준비한다
2. 새 노드의 데이터 필드에 값을 저장한다
3. 새 노드 왼쪽 노드의 오른쪽 링크 필드(rlink)에 있던 값을 새 노드의 오른쪽 링크 필드(rlink)에 저장한다
4. 왼쪽 노드의 오른쪽 링크 필드(rlink)에 새 노드의 주소를 저장한다
5. 새 노드 오른쪽 노드의 왼쪽 링크 필드(llink)에 있던 값을 새 노드의 왼쪽 링크 필드(llink)에 저장한다
6. 오른쪽 노드의 왼쪽 링크 필드(llink)에 새 노드의 주소를 저장한다
7. 노드를 순서대로 연결한다

### 알고리즘 4-9: 이중 연결 리스트의 노드 삽입

```
insertNode(DL, pre, x)
    new ← getNode()
    new.data ← x
    ① new.rlink ← pre.rlink
    ② pre.rlink ← new
    ③ new.llink ← pre
    ④ new.rlink.llink ← new
end insertNode()
```

**동작 설명 (초기 상태: DL → [100번지] ↔ [200번지] ↔ [300번지], pre=100번지, new=500번지):**

1. `new.rlink ← pre.rlink` : 노드 pre의 rlink(200번지)를 노드 new의 rlink에 저장 → 노드 pre의 오른쪽 노드(200번지)를 삽입할 노드 new의 오른쪽 노드로 연결
2. `pre.rlink ← new` : 새 노드 new의 주소(500번지)를 노드 pre의 rlink에 저장 → new를 노드 pre의 오른쪽 노드가 되도록 연결
3. `new.llink ← pre` : 포인터 pre의 값(100)을 삽입할 노드 new의 llink에 저장 → 노드 pre를 노드 new의 왼쪽 노드가 되도록 연결
4. `new.rlink.llink ← new` : 포인터 new의 값(500)을 노드 new의 오른쪽 노드(new.rlink, 200번지 노드)의 llink에 저장 → 노드 new가 오른쪽에 있는 노드의 왼쪽 노드로 연결

**최종 결과:**

```
DL → [100번지] ↔ [500번지(new)] ↔ [200번지] ↔ [300번지]
```

### 이중 연결 리스트에서 노드를 삭제하는 과정

> 💡 기차놀이 비유: 승희-철이-상원-수영에서 철이가 빠지는 과정 (양방향)
> 

① 양방향 기차놀이에서 사람(철이)이 빠지기 전 상태

② 철이 오른손에 있는 '상원' 이름표를 철이 왼쪽에 있는 승희 오른손에 넘겨준다

③ 철이 왼손에 있는 '승희' 이름표를 철이 오른쪽에 있는 상원이 왼손에 넘겨준다

④ 다시 이름표대로 연결 → 철이가 빠진 양방향 기차 완성

**정리:**

1. 삭제할 노드의 오른쪽 노드와 왼쪽 노드를 찾는다
2. 삭제할 노드의 오른쪽 노드의 주소(rlink)를 삭제할 노드의 왼쪽 노드(old.llink)의 오른쪽 링크 필드(rlink)에 저장한다
3. 삭제할 노드의 왼쪽 노드(old.llink)의 주소를 삭제할 노드의 오른쪽 노드(old.rlink)의 왼쪽 링크 필드에 저장한다
4. 노드를 순서대로 연결한다

### 알고리즘 4-10: 이중 연결 리스트의 노드 삭제

```
deleteNode(DL, old)
    ① old.llink.rlink ← old.rlink
    ② old.rlink.llink ← old.llink
    ③ returnNode(old)
end deleteNode()
```

**동작 설명 (old = 200번지 노드):**

1. `old.llink.rlink ← old.rlink` : 삭제할 노드인 old 오른쪽 노드의 주소(old.rlink, 300번지)를 노드 old 왼쪽 노드의 rlink(old.llink.rlink)에 저장 → 노드 old의 오른쪽 노드를 노드 old의 왼쪽 노드의 오른쪽 노드가 되도록 연결
2. `old.rlink.llink ← old.llink` : 삭제할 노드 old 왼쪽 노드의 주소(old.llink, 100번지)를 노드 old의 오른쪽 노드의 llink(old.rlink.llink)에 저장 → 노드 old의 왼쪽 노드를 노드 old의 오른쪽 노드의 왼쪽 노드가 되도록 연결
3. `returnNode(old)` : 삭제된 노드 old의 메모리를 반환한다

**최종 결과 (그림 4-35):**

```
DL → [100번지] ↔ [300번지]
(200번지 노드 삭제됨)
```

```c
linkedList_h* createLinkedList_h(void);
```

`[DoubleLinkedList.c]` 주요 구현:

```c
// pre 뒤에 노드를 삽입하는 연산  [알고리즘 4-9 구현]
void insertNode(linkedList_h* DL, listNode *pre, char *x) {
    listNode* newNode;
    newNode = (listNode*)malloc(sizeof(listNode));
    strcpy(newNode->data, x);
    if (DL->head == NULL) {
        newNode->rlink = NULL;
        newNode->llink = NULL;
        DL->head = newNode;
    }
    else {
        newNode->rlink = pre->rlink;
        pre->rlink = newNode;
        newNode->llink = pre;
        if (newNode->rlink != NULL)  // 삽입 자리에 다음 노드가 있는 경우
            newNode->rlink->llink = newNode;
    }
}

// 이중 연결 리스트에서 old 노드를 삭제하는 연산  [알고리즘 4-10 구현]
void deleteNode(linkedList_h* DL, listNode* old) {
    if (DL->head == NULL) return;          // 공백 리스트인 경우 삭제 연산 종단
    else if (old == NULL) return;          // 삭제할 노드가 없는 경우 삭제 연산 종단
    else {
        old->llink->rlink = old->rlink;
        old->rlink->llink = old->llink;
        free(old);                         // 삭제 노드의 메모리를 해제
    }
}

// 리스트에서 x 노드를 탐색하는 연산
listNode* searchNode(linkedList_h* DL, char* x) {
    listNode *temp;
    temp = DL->head;
    while (temp != NULL) {
        if (strcmp(temp->data, x) == 0) return temp;
        else temp = temp->rlink;
    }
    return temp;
}
```

## Section 05 - 연결 리스트의 응용 및 구현

### 1. 단순 연결 리스트를 이용한 다항식 표현

- 연결 리스트를 응용하여 다항식을 단순 연결 리스트로 표현하고 덧셈 연산을 구현하는 방법

### 노드 구조

각 항마다 **계수(coef)**와 **지수(expo)**를 저장 → 노드의 데이터 필드는 두 개 필드로 구성:

```
[ coef | expo | link ]
```

```c
typedef struct Node {
    float coef;
    int expo;
    struct Node *link;
};
```

### 다항식 표현 예시 (그림 4-37)

- **A(x) = 4x³ + 3x² + 5x**:

```
A → [4|3] → [3|2] → [5|1] → NULL
      4x³      3x²     5x¹
```

- **B(x) = 3x⁴ + x³ + 2x + 1**:

```
B → [3|4] → [1|3] → [2|1] → [1|0] → NULL
      3x⁴     1x³     2x¹     1x⁰
```

---

### 2. 다항식 연결 자료구조의 항 삽입 알고리즘

다항식 리스트 PL에 새로운 항(노드)을 추가할 때 **연결 리스트의 마지막 노드 다음에 새로운 노드를 추가**하는 알고리즘.

`appendTerm()` 함수 매개변수:

- `PL`: 다항식 리스트 포인터
- `coef`: coef 필드값을 저장한 변수
- `expo`: expo 필드값을 저장한 변수
- `last`: 리스트 PL의 마지막 노드의 위치를 지시하는 포인터

### 알고리즘 4-11: 다항식 끝에 항 추가

```
appendTerm(PL, coef, expo, last)
    new ← getNode()
    new.expo ← expo
    new.coef ← coef
    new.link ← NULL
    if (PL == NULL) then {
        ①-① PL ← new
        ①-② last ← new
    }
    else {
        ②-① last.link ← new
        ②-② last ← new
    }
end appendTerm()
```

**공백 리스트인 경우:**

- `PL ← new`: 포인터 new의 값을 리스트 포인터 PL에 저장 → new가 리스트 PL의 첫 번째 노드가 되도록 연결
- `last ← new`: 포인터 new의 값을 포인터 last에 저장 → 포인터 last가 리스트 PL의 마지막 노드인 new를 가리키도록 지정

**공백이 아닌 경우:**

- `last.link ← new`: 포인터 new의 값을 노드 last의 링크에 저장 → 노드 new를 노드 last의 다음 노드로 연결
- `last ← new`: 포인터 new의 값을 포인터 last에 저장 → 노드 new를 리스트 PL의 마지막 노드로 설정

---

### 3. 다항식끼리의 덧셈 연산과 알고리즘

두 다항식 A(x) + B(x) = C(x)를 단순 연결 리스트 자료구조를 사용하여 해결.

- 포인터 `p`: 다항식 A(x)에서 비교할 항을 가리킴
- 포인터 `q`: 다항식 B(x)에서 비교할 항을 가리킴
- 포인터 `r`: 덧셈 연산을 마치면 만들어지는 다항식 C(x)의 항을 지시

### 다항식 A의 지수(p.expo)와 B의 지수(q.expo) 비교 → 세 가지 경우

| 경우 | 처리 |
| --- | --- |
| `p.expo < q.expo` | 지수가 높은 항부터 나열하는 다항식 표현 규칙에 따라 포인터 q가 가리키는 B(x) 항을 C(x) 항으로 복사. q를 다음 노드로 이동 |
| `p.expo == q.expo` | 두 다항식의 계수를 더해 C(x) 항을 만듦. p.coef + q.coef를 r.coef에, 지수는 r.expo에 저장. 이후 p, q를 각각 다음 노드로 이동 |
| `p.expo > q.expo` | 포인터 p가 가리키는 A(x) 항을 C(x) 항으로 복사. p를 다음 노드로 이동 |

### 알고리즘 4-12: 단순 연결 리스트를 이용한 다항식 덧셈 연산

```
addPoly(A, B)
    p ← A;   q ← B
    C ← NULL              // 결과 다항식
    r ← NULL              // 결과 다항식의 마지막 노드
    while (p ≠ NULL and q ≠ NULL) do {
        case {
            p.expo == q.expo :
                sum ← p.coef + q.coef
                ②-① if (sum ≠ 0) then appendTerm(C, sum, p.expo, r)
                p ← p.link;   q ← q.link
            p.expo < q.expo :
                ②-② appendTerm(C, q.coef, q.expo, r)
                q ← q.link
            else :    // p.expo > q.expo인 경우
                ②-③ appendTerm(C, p.coef, p.expo, r)
                p ← p.link
        }
    }
    ③ while (p ≠ NULL) do {    // A의 나머지 항들 복사
        appendTerm(C, p.coef, p.expo, r)
        p ← p.link
    }
    ④ while (q ≠ NULL) do {    // B의 나머지 항들 복사
        appendTerm(C, q.coef, q.expo, r)
        q ← q.link
    }
    ⑤ return C
end addPoly()
```

### 덧셈 연산 단계별 예시

**A(x) = 4x³ + 3x² + 5x, B(x) = 3x⁴ + x³ + 2x + 1 → C(x) = 3x⁴ + 5x³ + 3x² + 7x + 1**

| 단계 | p | q | 처리 | C의 상태 |
| --- | --- | --- | --- | --- |
| 초기 | 4x³ | 3x⁴ | - | NULL |
| 1 | 4x³ | 3x⁴ | p.expo < q.expo → B의 3x⁴ 복사 | 3x⁴ |
| 2 | 4x³ | 1x³ | p.expo == q.expo → 4+1=5, 5x³ 추가 | 3x⁴ + 5x³ |
| 3 | 3x² | 2x¹ | p.expo > q.expo → A의 3x² 복사 | 3x⁴ + 5x³ + 3x² |
| 4 | 5x¹ | 2x¹ | p.expo == q.expo → 5+2=7, 7x 추가 | 3x⁴ + 5x³ + 3x² + 7x |
| 5 | NULL | 1x⁰ | B의 나머지 1x⁰ 복사 | 3x⁴ + 5x³ + 3x² + 7x + 1 |

**최종 C(x) = 3x⁴ + 5x³ + 3x² + 7x + 1**

### 4. 연결 리스트를 이용한 다항식 프로그램 (예제 4-5)

`[LinkedPoly.h]`

```c
#pragma once
// 다항식 리스트의 노드 구조를 구조체로 정의
float coef;
typedef struct ListNode {
    float coef;
    int expo;
    struct ListNode* link;
} ListNode;

// 다항식 리스트의 head 노드를 구조체로 정의
typedef struct ListHead {
    ListNode* head;
} ListHead;

ListHead* createLinkedList(void);
void appendTerm(ListHead* L, float coef, int expo);
void addPoly(ListHead* A, ListHead* B, ListHead* C);
void printPoly(ListHead* L);
```

`[LinkedPoly.c]` 주요 구현:

```c
// 다항식 리스트에 마지막 노드를 추가하는 연산  [알고리즘 4-11 구현]
void appendTerm(ListHead* L, float coef, int expo) {
    ListNode* newNode;
    ListNode* p;
    newNode = (ListNode *)malloc(sizeof(ListNode));
    newNode->coef = coef;
    newNode->expo = expo;
    newNode->link = NULL;

    if (L->head == NULL) {  // 다항식 리스트가 공백인 경우
        L->head = newNode;
        return;
    }
    else {                  // 다항식 리스트가 공백이 아닌 경우
        p = L->head;
        while (p->link != NULL) {
            p = p->link;    // 리스트의 마지막 노드를 찾음
        }
        p->link = newNode;  // 새 노드 연결
    }
}

// 두 다항식의 덧셈을 구하는 연산  [알고리즘 4-12 구현]
void addPoly(ListHead* A, ListHead* B, ListHead* C) {
    ListNode* pA = A->head;
    ListNode* pB = B->head;
    float sum;

    // 두 다항식에 노도가 있는 동안 반복 수행
    while (pA && pB) {
        // 다항식 A의 지수가 다항식 B의 지수와 같은 경우
        if (pA->expo == pB->expo) {
            sum = pA->coef + pB->coef;
            appendTerm(C, sum, pA->expo);
            pA = pA->link;  pB = pB->link;
        }
        // 다항식 A의 지수가 다항식 B 지수보다 큰 경우
        else if (pA->expo > pB->expo) {
            appendTerm(C, pA->coef, pA->expo);
            pA = pA->link;
        }
        // 다항식 A의 지수가 다항식 B의 지수보다 작은 경우
        else {
            appendTerm(C, pB->coef, pB->expo);
            pB = pB->link;
        }
    }
    // 다항식 A에 남아 있는 노드 복사
    for (; pA != NULL; pA = pA->link)
        appendTerm(C, pA->coef, pA->expo);

    // 다항식 B에 남아 있는 노드 복사
    for (; pB != NULL; pB = pB->link)
        appendTerm(C, pB->coef, pB->expo);
}

// 다항식 리스트를 출력하는 연산
void printPoly(ListHead* L) {
    ListNode* p = L->head;
    for (; p; p = p->rlink) {
        printf("%3.0fx^%d", p->coef, p->expo);
        if (p->link != NULL) printf(" + ");
    }
    printf("\n");
}
```

**실행 결과:**

```
A(x) = 4x^3 + 3x^2 + 5x^1
B(x) = 3x^4 + 1x^3 + 2x^1 + 1x^0
C(x) = 3x^4 + 5x^3 + 3x^2 + 7x^1 + 1x^0
```
